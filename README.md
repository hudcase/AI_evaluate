# 培训教学质量评估系统 · 端侧控制台

双模态（音频＋视频）课堂分析的培训教学质量评估系统，对应《技术路线-详细设计 v3.0》的 7 个功能模块：
建档、数据接入、数据治理、模型网关、指标计算、合成与一致性、报告与审计。界面共 9 个页面。

**整套系统零依赖、零构建**：后端只用 Python 标准库（`http.server` + `sqlite3`），前端是普通
`<script>`，没有 npm、没有框架、没有外链 CDN。评审现场没网、没权限装包也能跑起来。

本文回答四件事：**怎么跑起来、每个文件干什么、后端做了什么没做什么、哪些坑不要踩**。
实现细节（算法、表结构、请求链路）在 `docs/后端实现说明.md`。

## 一、跑起来

**前置**：Python 3.9 以上（推荐 3.10+），无需 `pip install` 任何东西。
浏览器用 Chrome / Edge / Firefox 近三年版本即可。

### 方式 A：桌面版（推荐，交付形态）

```
双击 software/启动桌面版.vbs
```

不弹黑框，直接开一个**没有地址栏、没有标签页**的应用窗口；关掉窗口就等于退出应用（服务一起停）。
数据落在 `%LOCALAPPDATA%\EvalConsole\data`，不在程序目录里——装到 `Program Files` 也能写。
端口自动挑（先试 8000，被占就换），不会因为端口冲突打不开。

有 Python 环境时它就是源码运行；跑过 `python build_win.py` 之后，`vbs` 会优先启动打包好的 exe。
启动失败（比如机器上没有 Python）会弹一句人话提示，而不是闪一下就没反应。

桌面版才有的能力：选文件夹批量入库、原生「选文件登记」、报告「另存为」、顶栏「退出」。
细节与设计取舍见 `docs/桌面版说明.md`。

### 方式 B：本地网页（开发调试）

```
双击 software/start.bat
```

它会启动后端，浏览器自动打开 `http://127.0.0.1:8000/`。界面与接口同源同端口，不存在跨域问题。
关闭黑窗口即停止。此模式下原生按钮不渲染，批量入库需要手贴清单 JSON。

### 方式 C：命令行

```bash
cd software
python backend/app.py --seed-demo          # 首次运行带上演示数据，默认 8000 端口
python backend/app.py --port 8080          # 换端口
python backend/app.py --reset-db --seed-demo   # 清库重建，回到干净的演示状态
python backend/app.py --no-open            # 不自动打开浏览器
python backend/app.py --host 0.0.0.0       # 允许局域网访问，便于评审投屏
```

数据库与媒体目录在首次运行时自动创建。

### 方式 D：只看界面（不启动后端）

```bash
cd software
python serve.py                 # 静态托管 frontend/，默认 5500 端口
```

默认配置连的是同源后端，此时没有后端，页面会显示错误提示。要纯看界面：

1. 打开 `frontend/assets/js/config.js`，把 `useMock` 改成 `true`（数据来自 `mock.js`，全部是造的）；
2. 刷新页面。

> `file://` 直开 `index.html` 也能看 mock 界面，但**接后端必须用方式 A 或 B**：`file://` 下浏览器
> 会以跨域为由拦截 `fetch`。

顶栏右上角的徽标会显示「已连接后端」或「演示数据」，随时能看出当前数据来源。

## 二、第一次打开该看什么

1. **总览**：4 个指标卡 ＋ 课次表。表里四个状态徽标是全系统的核心语义——可用、证据不足、
   证据不一致、处理中。点任意一行进入该场次详情。
2. **M6 合成与一致性**：音频分 `Sₐ` 与视频分 `Sᵥ` 并列，中间**没有总分位**。这是设计决定，不是缺失。
3. **M5 指标计算**：21 条指标的原始量、置信度、证据时间与分项分。点任意一行可补录观测值，
   补录后分数立刻重算（服务端 `membership.score()` 是唯一出口）。
4. **M7 报告与审计**：六节报告的样子，以及 DOCX 导出、销毁、审计留痕。

演示数据里四个场次各代表一种状态：

| 场次 | 状态 | 说明 |
| --- | --- | --- |
| `S-20261105-03` | 可用 | 四路采集齐备，两份分数并列输出 |
| `S-20261104-02` | 证据不一致 | 音频与视频结论差 ≥15 分，按规则判"分歧即证据不足" |
| `S-20261103-01` | 证据不足 | 覆盖率低于 60%，不出分数 |
| `S-20261105-04` | 处理中 | 有 running 任务，前端按阶段条显示进度 |

### 各文件职责边界

| 文件 | 负责 | 不负责 |
| --- | --- | --- |
| `frontend/config.js` | 后端地址、mock 开关、版本号 | 业务逻辑 |
| `frontend/api.js` | 发请求、错误归一化、mock/真实切换 | 渲染、业务判断 |
| `frontend/views/*.js` | 单页的取数、布局、交互 | 跨页共享状态 |
| `backend/app.py` | 路由、HTTP、静态托管 | 任何业务计算 |
| `backend/modules/*.py` | 参数校验、组装结果、状态码 | 算法 |
| `backend/core/membership.py` | 原始量 → 分项分 | 读写数据库 |
| `backend/core/gates.py` | 门禁判定 | 分数计算 |
| `backend/core/providers.py` | 外部模型调用、缓存、记账 | 业务规则 |
| `backend/db.py` | 连接、事务、查询 | 业务语义 |

页面之间不共享可变状态，只共享 `App.state.sessionId`（当前场次）。一个页面出问题不会连带其他页面。

## 四、导入你自己的课例数据

演示数据只是演示。真正要用起来，第一步是把已有的课放进系统。完整手册见 `docs/数据导入.md`，
这里只给最短路径。

### 4.1 按约定放好目录

```
原始数据/新任经理管理能力培训/
├── goals.txt                  课程目标，一行一条，首行为核心目标（必需）
└── 2026-11-05-0900/           目录名里的日期时间会被解析
    ├── cam1.mp4  cam2.mp4     机位
    ├── lavalier.wav           领夹麦
    ├── ambient_env.wav        环境声（名字含 ambient/env/环境）
    └── 课程课件.pptx           课件
```

### 4.2 一条命令导入

```bash
python backend/app.py --seed-demo                                    # 另开窗口起后端
python backend/tools/import.py scan ./原始数据 --consent --dry-run   # 先演练，只打印计划
python backend/tools/import.py scan ./原始数据 --consent --duration 90
```

- `--consent` 是"已取得知情同意"的声明，**不写就不建场次**——流程约束，不是选项；
- `--duration` 必须等于实际课时，否则"时间对齐"门禁会按偏差判 reject；
- 可以放心重跑：同名课程、同日期场次会复用，同场次同内容的文件按 sha256 判重跳过。

### 4.3 大文件不搬字节

```bash
python backend/tools/import.py scan ./原始数据 --consent --in-place
```

只登记盘上已有文件，不复制到 `data/media/`。sha256、探针、规格校验一样跑，适合几十 GB 的 4K 原片。
注意：销毁媒资会按登记路径删源文件，别把唯一副本登记进来又执行销毁。

### 4.4 三条硬规矩

1. **课程目标不能由工具编**：至少要有一条 `core` 目标，A2 加权覆盖的分母靠它；
2. **知情同意必须显式声明**：否则 400 `CONSENT_REQUIRED`；
3. **规格不对直接拒收**：分辨率 < 1280×720、采样率 < 16 kHz、削波 > 2%、不是有效 MP4/WAV
   → 422，逐条列出问题。该重录就重录，不要"先导进去再说"。

指标原始量（`raw_value`）单独走 CSV：`python backend/tools/import.py obs 观测.csv --session S-xxx`。
分数不用导入，也不允许导入——分项分只能由服务端按量尺算。

## 五、后端做了什么

### 5.1 一句话概括

**能算的真算，算不了的显式留空并说明要补什么。** 没有任何"看起来有数、其实是编的"的地方：
没有 ffmpeg 就不假装做过转码，没接模型就把门禁记成"未测"，provider 是桩就把调用标 `simulated=true`。

### 5.2 模块完成度

| 模块 | 接口数 | 状态 | 说明 |
| --- | --- | --- | --- |
| M1 建档 | 6 | 完整 | 课程、场次、课程目标；场次编号按当日最大号 +1，不会重号 |
| M2 数据接入 | 3 | 完整 | 三条路：multipart 直传、就地登记（只记路径不搬字节）、仅登记；预签名直传留 501 |
| M3 数据治理 | 5 | 完整 | 六阶段流水线真跑；无 ffmpeg 时该阶段 `skipped` 并写原因 |
| M4 模型网关 | 2 | 完整（桩） | 缓存／重试／记账真跑；真模型下 ASR／OCR／VLM 留 501 |
| M5 指标计算 | 5 | 完整 | 21 条指标、观测值校验、门禁阻断、分数重算 |
| M6 合成与一致性 | 2 | 完整 | 覆盖率＝可用权重和；分歧判定；VB1 时序 |
| M7 报告与审计 | 2 | 完整 | DOCX／HTML 真生成；PDF 留 501（需中文字体嵌入） |
| 系统 | 2 | 完整 | 总览聚合与健康度全部现算，不读缓存表 |

### 5.3 留空的接口与怎么接

留空的接口一律返回 `501 NOT_IMPLEMENTED`，`message` 里写明**缺什么、去哪补**。前端对应按钮
置灰或给提示，不会假装成功。

| 位置 | 留空原因 | 接法 |
| --- | --- | --- |
| `POST /api/sessions/{id}/media`（`action=presign`） | 需要对象存储的签名服务（MinIO／OSS／S3） | 在 `modules/m2_media.py` 的 `register()` 里实现签名；或继续用 multipart 直传 |
| `GET .../report?format=pdf` | 需嵌入中文字体子集，端侧不引字体文件 | 导出 DOCX 后在 WPS 另存 PDF，或浏览器打印报告页 |
| `provider=openai` 下的 `asr`／`ocr`／`vlm` | 各家协议差异大（录音文件识别、OCR、多模态的请求体都不一样） | 在 `core/providers.py` 的 `OpenAIProvider` 补一个方法；记账、缓存、重试逻辑不用改 |
| 流水线 `mask` 阶段（ROI 打码） | 需人脸／人体检测模型 | 在 `core/pipeline.py` 的 `stage_mask()` 接检测后逐帧打码；在此之前原片不得离开端侧 |
| 流水线 `parse_slides` 对 PDF 课件 | 需版面分析才能取正文（PPTX 已能直接解） | 走 OCR provider；当前只记页数 |

### 5.4 模型网关的三种状态

| `MODEL_PROVIDER` | 行为 | 界面表现 |
| --- | --- | --- |
| `stub`（默认） | 不联网。按 `input_hash` 派生**确定性**占位结果，同一输入永远同一结果，便于回归 | 五类能力显示「桩」，横幅标注「桩 · 模拟」，成本备注「估算值」 |
| `openai` | 走 OpenAI 兼容端点。`llm`／`embed` 已实现，其余三个留 501 | 五类能力按实际可用性显示正常／不可用 |
| `none` | 全部返回 503 | 五类能力全部「不可用」 |

三条不变量在三种状态下都成立：**逐次写 `ai_calls`**、**`model_version` 与 `prompt_version` 缺一即拒（400）**、
**同 `input_hash` 在 7 天 TTL 内命中缓存不重复计费**。

### 5.5 探针能测什么、测不了什么

不依赖 ffprobe，自己解容器。这是为了让"没有 ffmpeg 的评审机"也能跑通规格校验。

| 格式 | 能测 | 方法 |
| --- | --- | --- |
| MP4 | 时长、分辨率、帧率、轨道数、码率 | 解析 `ftyp`／`mvhd`／`tkhd`／`stsz` box |
| WAV | 采样率、位深、声道、时长、峰值、削波占比 | 解析 RIFF 的 `fmt`／`data`，尾部 8 MB 抽样 |
| PPTX | 幻灯片页数、纯图页数 | 解压数 `slideN.xml`，统计无文本框的页 |
| PDF | 页数 | 数 `/Type /Page` 对象 |

**测不了的**：画面清晰度、遮挡、噪声类型、转写正确率、后排检测率——这些是内容层面的，
只能由模型产出。所以它们出现在 `task.result_json.model_metrics` 里，缺了就在门禁里记"未测"，
**不补零、不猜**。

### 5.6 九张表

`courses`（课程）、`sessions`（场次与课程目标）、`media_assets`（媒资）、`ai_tasks`（预处理任务）、
`ai_calls`（每次模型调用的流水）、`observations`（21 条指标的观测值）、`indicator_config`（按版本管理的指标配置）、
`evaluations`（评价快照，字段 `composite` 恒为 null，显式表达"不合成"）、`audit`（审计）。

字段与约束见 `backend/schema.sql`，设计理由见 `docs/后端实现说明.md`。

### 5.7 配置

全部可调项集中在 `backend/config.py`，用环境变量覆盖，部署时不必改代码：

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `EVAL_DATA_DIR` | `software/data` | 数据目录（库、媒体、导出） |
| `EVAL_DB` | `<data>/eval.db` | 库文件路径 |
| `EVAL_HOST` / `EVAL_PORT` | `127.0.0.1` / `8000` | 监听地址与端口 |
| `MODEL_PROVIDER` | `stub` | `stub`／`openai`／`none` |

## 六、自测

```bash
# 一个终端起服务（用临时数据目录，别污染正式库）
EVAL_DATA_DIR=/tmp/smokedata python backend/app.py --port 8790 --reset-db --seed-demo --no-open

# 另一个终端跑自测
python backend/tests/smoke.py --base http://127.0.0.1:8790
```

期望输出 `91 通过，0 失败`。断言分两类：

- **契约断言**：字段、状态码、错误码与 `docs/接口约定.md` 一致；
- **口径断言**：不合成总分、缺测不补零、覆盖率＝权重和、门禁阻止计分、分歧即证据不足——
  这些是评价规则，改代码时最容易被顺手改掉，所以用测试钉死。

## 七、数据目录与重置

- 所有运行期数据在 `software/data/`，删掉整个目录即回到出厂状态（下次启动自动重建）。
- `eval.db` 用 WAL 模式，会看到 `-wal` 与 `-shm` 两个伴生文件，**备份时要三个一起拷**
  （或先停服务再拷）。
- 换机器迁移：拷 `data/` 整个目录，再启动即可。
- 媒体文件按 `<场次>/<类型>/<文件名>` 存在 `data/media/`，接口返回的 `path` 是相对路径。

## 八、扩展方式

### 加一个指标

1. 在 `backend/seed/indicators.json` 加一条（`code / tier / domain / weight / direction / a,b,c,d / unit`）；
2. 重新发布配置版本：`PUT /api/indicators`，或在指标配置页保存；
3. 前端自动渲染——M5 指标表与指标配置页都是配置驱动，没有硬编码 21 条。

**注意**：同域权重和必须等于 1.0000，接口会校验；改权重等于改口径，要同步 `docs/`。

### 接真模型

1. 设 `MODEL_PROVIDER=openai`、`MODEL_BASE_URL`、`MODEL_API_KEY`；
2. `llm`／`embed` 立刻可用；
3. ASR／OCR／VLM 按厂商在 `core/providers.py` 补方法——请求体不同，其余（缓存、重试、记账、
   `simulated` 标记、`model_version` 校验）全部复用。

### 加一个模型能力

1. `core/providers.py` 的 `CAPABILITIES` 加一项，并在各 provider 里给出 `health` 与 `call`；
2. `views/gateway.js` 的 `CAPS` 数组加一项（名称、说明、输出去向）；
3. `/api/health` 的 `providers` 自动带上这个 key，状态灯自动出现。

### 加一个页面

1. `views/` 下新建文件，实现 `Views.xxx = function (el, ctx) { ... }`；
2. `index.html` 加一行 `<script>`；
3. `app.js` 的 `ROUTES` 加一行 `{path, title, view, group, desc}`。

导航、路由、高亮、面包屑都会自动生成。

## 九、几条不要改错的口径

改界面或改后端时最容易破坏的是下面几条。它们不是视觉偏好，是评价规则：

1. **不合成总分**。音频分与视频分必须并列，不设"教学质量总分"。加权合成等于宣称两者可通约，
   而两份来源材料都没能给出 α。
2. **缺测不补零、不重分权**。某指标没数据时记空值并写原因；模态分只在可用分项上求和，
   覆盖率单独报。覆盖率 0.90 时，模态分的理论上限就是 90。
3. **分项分满分 100，但不是达成率**。它只表示该项在其量尺上的取值。报告里不能出现
   "学员满意度""培训效果"这类本系统无权得出的说法。
4. **门禁先于计分**。`reject` 的分项必须显示"未输出"而不是 0；被阻断的指标在 M5 里记空值 + 原因。
5. **C1 与 VC3 不计分**。C1 是合规门禁，只出候选事件清单；VC3 是结果层列示项，无当堂测验就没有数据源。
6. **权重和恒为 1.0000**。VC3 移出计分域后，视频 10 项已全局等比例配平；不要再写"0.97 上归一"。

## 十、常见问题

**端口被占用**：`python backend/app.py --port 8080`。

**改了代码没生效**：静态响应带 `no-store`，普通刷新即可；仍不对就 `Ctrl+F5`。

**页面空白、控制台报错**：F12 看 Console。多半是某个 `views/*.js` 语法错误导致 `Views` 未注册，
此时壳层会显示"页面未实现"。

**中文显示成方块**：系统缺中文字体。Windows 自带微软雅黑，Linux 需装 `fonts-noto-cjk`。

**一致性率显示"—"**：`/api/health` 的一致性率只统计**有证据**的场次；全部场次都证据不足时返回
`null`，界面显示"—"而不是 0%——0% 会被读成"一致性极差"。

**导出 PDF 按钮是灰的**：PDF 留接口（501），要把报告给外部时用 DOCX 导出后在 WPS 另存。

**预处理一直"跳过"**：机器上没有 ffmpeg。转码抽帧需要它；没有时六阶段会显式 `skipped`，
门禁"画面可用性"随之变 warn——系统不会假装做过。

**上传报 `SPEC_MISMATCH`**：文件与场次规格不符（4K／48kHz／时长）。这是**故意拦的**：
规格不对时后面对齐和抽帧都没有意义，应该在采集端重录，而不是让数据混进来。

## 十一、当前状态与已知限制

- **前端完整可跑**，9 个页面均有真实交互（新增课程、创建场次、上传登记、补录观测、导出、销毁确认）。
- **后端可用**，37 个接口全部有实现，其中 3 处按能力留空（预签名直传、PDF 导出、真模型下的
  ASR／OCR／VLM），另有两个流水线阶段显式跳过（ROI 打码、PDF 课件正文），见 5.3。
- **模型全部是桩**。除 `llm`／`embed` 外没有接真实推理；分数由观测值经量尺折算而来，
  观测值本身在真实部署前需要模型产出。
- **不做鉴权与多用户**。单机单用户原型，接口已按 `Authorization: Bearer` 预留；
  但已做跨站写请求防护（见 `docs/接口约定.md` 第十一节）。
- **不做移动端**。桌面端操作工具，1024px 以下不优化。
- **图表是内联 SVG**，只覆盖 VB1 抬头率时序一种。
- **桌面版仍是"浏览器内核 + 本地服务"**：任务栏图标是 Edge 的（`--app` 模式换不了图标），
  没有代码签名与安装器，也没做自动更新。见 `docs/桌面版说明.md` 第七节。
- 版本 `v0.3.0`（桌面化），`config.js` 的 `version` 字段同步。
