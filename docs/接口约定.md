# 后端接口约定

> 本文是前后端的唯一契约。前端已按此实现（`frontend/assets/js/api.js`），后端照此实现即可对接。
> 所有路径省略公共前缀 `/api` 时已标注；时间一律 ISO 8601（`2026-11-05T19:30:00+08:00`），时长单位秒。

## 一、通用约定

| 项 | 约定 |
| --- | --- |
| Base URL | `http://127.0.0.1:8000`（端侧主机，见 `config.js`） |
| 编码 | UTF-8，`Content-Type: application/json` |
| 幂等 | `GET/PUT/DELETE` 幂等；`POST` 非幂等，重试需带 `Idempotency-Key` |
| 分页 | `?page=1&size=20`，响应含 `{"items":[],"total":0,"page":1,"size":20}` |
| 请求体上限 | 64 KiB（媒资走 multipart 直传或就地登记，不计入） |
| 鉴权 | `Authorization: Bearer <token>`；原型期可关闭，但接口须预留 |
| 版本 | 路径不带版本号，破坏性变更以 `X-Api-Version` 请求头切换 |
| 时间戳 | 证据时间 `evidence_t` 为**相对课程起点的秒数**（浮点），非绝对时间 |

### 错误响应

统一结构，HTTP 状态码语义标准：

```json
{
  "error": {
    "code": "GATE_NOT_PASSED",
    "message": "视频检测敏感性未通过，VB1 不予输出",
    "field": "observations[7].code",
    "trace_id": "8f3c1d2e"
  }
}
```

| code | HTTP | 含义 |
| --- | --- | --- |
| `VALIDATION_FAILED` | 400 | 字段校验失败，`field` 指明位置 |
| `CONSENT_REQUIRED` | 400 | 场次未确认知情同意，不得入库 |
| `SPEC_MISMATCH` | 422 | 媒资规格不符（分辨率、采样率、编码、页数） |
| `GATE_NOT_PASSED` | 409 | 门禁未通过，相关分项不得计分 |
| `MISSING_GOALS` | 409 | 缺课程目标文本，目标匹配域不可计算 |
| `TASK_CONFLICT` | 409 | 同一场次已有运行中的预处理任务 |
| `NOT_FOUND` | 404 | 对象不存在 |
| `PROVIDER_UNAVAILABLE` | 503 | 模型服务不可用，已重试 3 次 |
| `QUOTA_EXCEEDED` | 429 | 模型调用配额耗尽 |
| `PII_DETECTED` | 400 | `evidence_note` 含手机号／身份证／邮箱 |

## 二、M1 建档

### GET /api/courses

```json
{
  "items": [
    {
      "id": "C-20261105-01",
      "title": "新员工安全生产培训",
      "goals": [
        {"text": "能识别车间三类高危作业场景", "tier": "core"},
        {"text": "能正确佩戴与检查防护装备", "tier": "core"},
        {"text": "能说明事故上报流程", "tier": "support"}
      ],
      "expected_students": 42,
      "created_at": "2026-11-05T08:10:00+08:00"
    }
  ],
  "total": 1, "page": 1, "size": 20
}
```

`goals` 约束：1–30 条，`tier ∈ {core, support, extend}`，`text` ≤ 200 字符。`core` 参与 A2 加权覆盖的分母，权重由 `tier` 映射（core=3／support=2／extend=1），不单独存权重。

### POST /api/courses

请求体同上（无 `id`／`created_at`）。校验：`title` 1–100 字符；`goals` 至少 1 条且至少 1 条 `core`；`expected_students` 1–10000。

响应 `201 {"id":"C-20261105-01"}`。

### GET /api/courses/{id}

返回单个课程，附 `sessions[]` 摘要（`id / title / scenario / created_at / status`）。

### DELETE /api/courses/{id}?confirm=true

删除课程及其全部派生数据，**不可逆**。必须带 `confirm=true`，否则返回 `400 VALIDATION_FAILED`。

级联删除顺序（按子表 → 父表，无外键级联，显式逐表删）：`observations → evaluations → ai_calls → ai_tasks → media_assets → sessions → courses`；媒资的物理文件与 `data/media/<session>/` 派生目录一并删除。`audit` 表保留，且「删除课程」这一动作本身也会写入审计。

响应 `200 {"id":"C-20261105-01","deleted_sessions":2}`。

### POST /api/import

批量入库（与 `tools/import.py` 的 manifest 同构）。一次提交一份清单，后端按「课程 → 场次 → 媒资 → 观测」顺序逐项落库、逐项回报；媒资走**就地登记**（`path` 已在盘上，不搬字节）。

```json
{
  "courses": [{
    "title": "新任经理管理能力培训", "expected_students": 32,
    "goals": [{"text": "能说清管理者的三项核心职责", "tier": "core"}],
    "sessions": [{
      "title": "第一讲 角色认知", "date": "2026-11-05", "start": "09:00",
      "duration_min": 90, "scenario": "theory", "teacher": "张某", "room": "A301",
      "consent_confirmed": true,
      "media": [{"path": "D:/原始数据/cam1.mp4", "type": "video", "slot": "cam1"}],
      "observations": [{"code": "A2", "raw_value": 0.82, "confidence": 0.9}]
    }]
  }]
}
```

- 幂等：课程按标题、场次按日期+开始时间+标题复用，重跑不重复建课。
- 逐项回报：某一条媒资缺失/规格不符只影响该条（`failed` 计数 +1），不整批回滚——批量导入的本质是「能进的进，进不去的单独报」。
- 响应 `201`，含 `courses / sessions / assets / observations / duplicate / failed` 计数与 `items[]` 逐项结果。

### POST /api/sessions

```json
{
  "course_id": "C-20261105-01",
  "title": "第三讲 高处作业防护",
  "scenario": "theory",
  "consent_confirmed": true,
  "teacher": "T-014",
  "room": "A-302",
  "expected_students": 42
}
```

- `scenario ∈ {theory, seminar, practical}`——B1 语速区间与VB1 警戒线按课型取值
- `consent_confirmed` 必须为 `true`，否则返回 `400 CONSENT_REQUIRED`
- 响应 `201 {"id":"S-20261105-03","status":"created"}`

## 三、M2 数据接入

### POST /api/sessions/{id}/media

三条登记通道，按**文件在哪**选，不是按文件大小选：

| 通道 | 请求形态 | 文件去哪 | 适用 |
| --- | --- | --- | --- |
| A multipart 直传 | `multipart/form-data` | 复制进 `data/media/<session>/` | 课件、现场音频、≤ 2 GiB 的视频 |
| B 就地登记 | JSON 带 `path` | **不复制**，保留原路径 | 4K 原片、一次课几十 GB |
| C 仅登记 | JSON 无 `path` 无字节 | 无文件 | 补录历史资产、演示；页面显示"未落盘" |
| D 预签名直传 | `action=presign` | — | **未实现（501）**，接对象存储时再补 |

`type ∈ {video, audio, slides, goals}`；`slot` 对 video 为 `cam1..cam4`，对 audio 为 `lavalier|ambient`，对 slides 为 `deck`，对 goals 为 `goals`（省略时取该 type 的第一个）。新增 `replace=true` 才能替换同一 slot 上已有的资产，否则返回 `409 STATE_CONFLICT`。

**A. multipart 直传**（≤ 2 GiB）

```
POST /api/sessions/S-20261105-03/media
Content-Type: multipart/form-data

type=video
file=@cam1.mp4
slot=cam1
```

**B. 就地登记**（大文件走这条）

```json
POST /api/sessions/S-20261105-03/media
{"type":"video","slot":"cam1","path":"D:/采集/1105/cam1.mp4"}
→ 201 {"asset_id":"M-3f9a21","type":"video","slot":"cam1","name":"cam1.mp4",
        "bytes":16106127360,"sha256":"c1f4e9…","duration_s":5400.0,
        "probe":{"width":3840,"height":2160,"fps":25.0,"codec":"hevc"},"stored":true,"duplicate":false}
```

`sha256`、探针、规格校验与直传**完全一致**，唯一差别是不搬字节：`stored=true` 但 `path` 指向原位置，审计记 `media.register_local` 且 `in_place:true`。路径不存在返回 `400 VALIDATION_FAILED`（`field=path`）。

> ⚠ 销毁媒资时按登记的 `path` 删源文件。不要把采集机上**唯一副本**登记进来再执行 `DELETE ...?scope=raw`。

**C. 仅登记**（无文件字节）

```json
{"type":"video","slot":"cam1","name":"cam1.mp4","duration_s":5400,"sha256":"c1f4e9…"}
```

`status` 记 `registered`，`stored=false`，`sha256` 可为 `null`。若同时给了 `probe`，就按它校验规格（不符即 422）；不给则跳过校验，流水线探针阶段会把这类资产标为 `degraded`。

**D. 预签名直传**（返回 501 `NOT_IMPLEMENTED`）

```json
{"type":"video","slot":"cam1","action":"presign","bytes":16106127360}
```

形状按原设计保留（`upload_url` / `asset_id` / `expires_at` + `action=commit`），端侧单机部署没有对象存储与签名服务，故留空。超过 2 GiB 的文件请走通道 B。

**规格校验（硬约束，不通过即 422 `SPEC_MISMATCH`）**

| type | 校验项 |
| --- | --- |
| video | 3840×2160、25fps、H.265 或 H.264、时长与场次一致、**必须是有效 MP4（能读到 ftyp／moov）** |
| audio | PCM16、48000 Hz、单声道或双声道、无削波 |
| slides | PPTX 优先，PDF 次之，页数 1–300 |

`probe` 与 `problems` 一并回在 `error.detail` 里，便于前端提示具体哪一项不符。

**响应**（三条通道同形，201）

```json
{
  "asset_id": "M-3f9a21",
  "id": "M-3f9a21",
  "type": "video",
  "slot": "cam1",
  "name": "cam1.mp4",
  "sha256": "c1f4e9…",
  "bytes": 16106127360,
  "duration_s": 5400.0,
  "probe": {"width": 3840, "height": 2160, "fps": 25.0, "codec": "hevc", "bitrate_mbps": 16.2},
  "retention_days": 7,
  "status": "ok",
  "stored": true,
  "duplicate": false
}
```

**判重语义**：`duplicate=true` 表示**同一场次内** sha256 命中已有资产，服务端不重复存储，直接返回原 `asset_id`（此时 HTTP 仍为 201，前端据此提示"已存在"）。

判重范围只到场次，不是全库——同一份课件、同一段演示录像被多节课复用是正常情况，全库判重会把第二节及之后的课全部拦掉。跨场次复用请直接再登记一次，各场次独立持有自己的 `media_assets` 行。

### GET /api/sessions/{id}/media

返回该场次已登记资产清单（`stored` 区分"已落盘"与"仅登记"），前端用于渲染四类输入的完成度：

```json
{"items":[{"id":"M-3f9a21","type":"video","slot":"cam1","name":"cam1.mp4","bytes":16106127360,
           "sha256":"c1f4e9…","duration_s":5400.0,"probe":{},"retention_days":7,
           "status":"ok","created_at":"2026-11-05T19:30:00+08:00","stored":true}]}
```

### DELETE /api/sessions/{id}/media?scope=raw|derived|all&confirm=true

`scope=raw` 删视频／音频原片，`derived` 只清派生目录，`all` 全清并把场次退回 `created`。响应 `{"deleted":["M-..."],"freed_bytes":16106127360,"note":"观测与评价快照不随媒资删除，报告仍可复核"}`。缺 `confirm=true` 返回 `400`。

### DELETE /api/sessions/{id}/media/{asset_id}?confirm=true

逐条撤销登记（传错文件、选错机位都走这条），删完该 `slot` 立刻可以重新登记，不必整场销毁。缺 `confirm=true` 返回 `400`，已删过的资产返回 `409`，不存在的返回 `404`。

```json
→ 200 {"deleted":["M-3f9a21"],"type":"video","slot":"cam1","freed_bytes":16106127360,
       "file":"removed","remaining":4,"stage":"report","stale":true,
       "note":"观测与评价快照不随媒资删除；该场次已有处理结果，需重新预处理才会更新"}
```

`file` 说明盘上文件怎么处理的：

| 值 | 含义 |
|---|---|
| `none` | 仅登记、没有落盘字节，无需处理 |
| `removed` | 已从盘上删除（系统自有副本 `data/media/<sid>/` 下的文件） |
| `kept` | 就地登记的外部文件，**只解除登记、原文件保留**（可能是采集机上的唯一副本） |
| `failed` | 文件在但删不掉（被占用或无权限），记录仍已删除 |

`stale=true` 表示该场次已走过预处理／评分，删源不会自动重算，需重新 `POST /preprocess`。要连外部原文件一并删除，显式加 `purge=true`（危险，前端不提供入口）。

## 五、M4 模型网关（内部接口，前端只读日志）

### POST /ai/{capability}

`capability ∈ {asr, ocr, embed, llm, vlm}`。四类请求／响应：

```json
// asr
{"audio_url":"s3://asr_in/S-…/lavalier_16k.wav","language":"zh","diarization":true,"word_timestamps":true}
→ {"segments":[{"start":12.4,"end":18.9,"text":"…","speaker":"teacher","conf":0.93}]}

// ocr
{"image_urls":["…/slide14.png"],"lang":"zh"}
→ {"pages":[{"no":14,"blocks":[{"text":"…","bbox":[120,340,860,90],"conf":0.96}]}]}

// embed
{"texts":["能识别车间三类高危作业场景"]}
→ {"vectors":[[0.013,-0.221,…]],"dim":1024}

// llm
{"slices":[{"t0":640.0,"t1":700.0,"text":"…"}],"indicator":"A2","schema":{…}}
→ {"items":[{"code":"A2","value":0.86,"confidence":0.88,"evidence_t":750.0,"reason":"…"}]}

// vlm
{"frame_urls":["…"],"prompt_version":"vlm-frame-v3"}
→ {"present":38,"facing":0.61,"confidence":0.70,"note":"第 12–14 分钟抬头率下降"}
```

**网关强制行为**：所有调用写 `ai_calls`；`model_version`、`prompt_version` 缺失即 `400`；同一 `input_hash` 在 TTL 内命中缓存则不重复计费（响应带 `cached: true`）。

## 六、M5 指标计算

### POST /api/sessions/{id}/observations

```json
{
  "code": "A2",
  "raw_value": 0.86,
  "denominator": 1.0,
  "unit": "ratio",
  "confidence": 0.88,
  "evidence_t": 750.0,
  "source_track": ["audio", "slides"],
  "evidence_note": "核心目标 3/3 命中，证据见 12:30",
  "model_version": "asr-2026-09"
}
```

**校验要点**

- `raw_value` 必须落在该指标登记的量纲范围内（如 B1 语速为 80–320 字/分），**不是统一的 0–1**；量纲区间只挡明显输错的量级，不做业务判断
- `raw_value` 允许为 `null`——空值不是"没这条"，而是"没测到"。此时应带 `empty_reason`，服务端记 `score=null` 并压低覆盖率，**不补零、不重分权**
- `evidence_note` ≤ 120 字符；命中手机号／身份证／邮箱返回 `400 PII_DETECTED`
- `source_track` 为数组，取值 `{audio, video, slides, goals}`；VA5、VC1、VB3 在有观测值时必须 ≥ 2 项（空值不受此限）
- `confidence ∈ [0,1]`
- 门禁 `reject` 的指标不允许补录，返回 `409 GATE_NOT_PASSED`；不计分项（VC3 等）返回 `400`

**响应** `201`，分项分由服务端按 `indicator_config` 的量尺计出，**客户端不得自行给分**：

```json
{"id": "O-9f2a", "code": "A2", "score": 86.0, "confidence": 0.88, "coverage_after": 0.34}
```

### POST /api/sessions/{id}/score

按当前 `indicator_config` 重算全部分项分。用于阈值改版后复算：

```json
{"config_version": "2026-11-01"}
→ {"scored": 19, "empty": 2, "audio_coverage": 0.90, "video_coverage": 1.00}
```

### GET /api/sessions/{id}/observations

返回 21 条指标的完整记录（含空值项），字段同上加 `score`。`denominator` 是文字规则：
观测未填时取 `indicator_config.denominator_rule`（如「核心目标权重和」「可评价时长」），
不是数值，也不参与算分。

```json
{"items":[{"code":"B3","name":"口音可懂度","tier":"audio","weight":0.10,
  "raw_value":null,"denominator":"盲听词次","unit":"ratio","score":null,
  "confidence":null,"evidence_t":null,"source_track":["audio"],
  "empty_reason":"无盲听数据，无人工环节下不可得"}]}
```

## 七、M6 合成与一致性

### GET /api/sessions/{id}/evaluation

无请求体，读库现算并落 `evaluations` 快照：

```json
{
  "session_id": "S-20261105-03",
  "config_version": "2026-11-01",
```

**关键约定**

- `composite` 恒为 `null`——规则一「并列不合成」，服务端不提供总分字段

## 十、桌面端能力（`/api/desktop/*`）

这一组接口只在桌面版（`desktop/main.py` 启动）里真正可用。用浏览器打开时
`GET /api/desktop/info` 会回 `desktop:false`，其余接口一律 `501 NOT_IMPLEMENTED`——
前端据此**不渲染**原生按钮，所以不会出现"点了没反应"。

存在的原因：浏览器给不了真实路径（`<input type=file>` 只给 `C:/fakepath/...`），
而本系统的媒资入库是「就地登记」，几十 GB 原片只记路径不搬字节，路径必须是真的。

### GET /api/desktop/info

```json
{"desktop": true, "available": true, "shell": "edge-app", "version": "0.3.0",
 "data_dir": "C://Users//x//AppData//Local//EvalConsole//data",
 "log_dir": "...", "export_dir": "...", "db_path": "...",
 "frozen": false, "python": "3.13.14", "port": 8000}
```

`shell` 取值：`webview`（pywebview）／`edge-app`／`chrome-app`／`browser`。
此接口同时充当页面报到，用于判断"窗口还在"。

### GET /api/desktop/ping

页面每 20 秒一次。5 分钟内没有任何报到，桌面端会自行退出（避免页面崩溃后留孤儿进程）。

### POST /api/desktop/bye

页面关闭／刷新时由 `navigator.sendBeacon` 发出。**不会立即退出**：只挂 3 秒倒计时，
新页面载入后调用 `info` 即抵消（刷新无感）。倒计时到期后桌面端还会按"窗口是否仍存在"复核。

### POST /api/desktop/dialog/folder

```json
请求 {"title":"选择课程根目录","initial":"D:/原始数据"}
响应 {"path":"D://原始数据","cancelled":false}
```

原生文件夹对话框（Win32 `SHBrowseForFolderW`）。用户取消时 `path:null`、`cancelled:true`。
同一时刻只允许一个对话框，重复调用返回 `409 STATE_CONFLICT`。

### POST /api/desktop/dialog/files

```json
请求 {"title":"选择视频","filters":["视频|*.mp4;*.mov"],"multiselect":false}
响应 {"paths":["D://原始数据//cam1.mp4"],"cancelled":false}
```

`filters` 为 `"显示名|*.ext;*.ext"` 数组；`multiselect` 默认 `true`。

### POST /api/desktop/dialog/save

```json
请求 {"title":"导出报告","filename":"报告.docx","filters":["Word 文档|*.docx"],"default_ext":"docx"}
响应 {"path":"D://报告.docx","cancelled":false}
```

### POST /api/desktop/scan

把目录树翻成批量入库清单（与 `tools/import.py scan` 同一套目录约定），供人确认后再提交。

```json
请求 {"root":"D:/原始数据","consent":true,"scenario":"theory","duration_min":90}
响应 {"root":"...","manifest":{"courses":[...]},"issues":[{"level":"error","where":"课程A / 场次1","text":"..."}],
      "stats":{"courses":1,"sessions":2,"media":5,"bytes":123}}
```

- **不猜业务字段**：缺 `goals.txt`／`goals.json` 的课程会在 `issues` 里报 `error`，不会替用户编目标；
- `issues.level`：`error`（提交后会被拒收）／`warn`（不影响入库）；
- 已存在的课程／场次会带 `exists:true` 与对应 id，方便预判"这次是新建还是复用"。

### POST /api/desktop/save-report

```json
请求 {"session_id":"S-20261105-05","format":"docx","path":"D://报告.docx"}
响应 {"saved":"D://报告.docx","bytes":38142,"content_type":"...","suggested":"课堂教学质量评估报告-S-20261105-05.docx"}
```

由后端直接把报告写到用户选的路径，不经浏览器下载目录。
**必须是 POST**：若开放成 GET，别的网页放一个 `<img src=...>` 就能触发任意路径写入。
`format=json` 时写的就是报告结构体本身。

### POST /api/desktop/quit

```json
请求 {"confirm":true}
响应 {"ok":true,"message":"正在退出"}
```

先回包再退（0.4 秒后），否则前端拿到的是 `connection reset`，看起来像崩溃。
退出顺序：停 HTTP 服务 → 关窗口（`WM_CLOSE`）→ 删 `runtime.json` → 进程退出码 0。

### POST /api/desktop/reveal

```json
请求 {"path":"D://导出//报告.docx"}
响应 {"ok":true,"path":"..."}
```

在资源管理器里定位文件／打开文件夹。失败返回 `ok:false`，不抛错——定位不到不该打断主流程。

## 十一、跨站写请求防护

单机部署时后端监听 `127.0.0.1`，浏览器里任意网页都能向它发"简单请求"（表单 POST 不触发预检），
读不到响应也足以改数据。因此：

- 非 GET/HEAD/OPTIONS 请求，若带 `Origin` 且不在本机白名单 → `403 FORBIDDEN`；
- 带 `Sec-Fetch-Site` 且不是 `same-origin`／`none` → `403 FORBIDDEN`；
- `Access-Control-Allow-Origin` 不再无条件 `*`：只有 `--host 0.0.0.0`（局域网演示）才放开。

本机脚本（curl、`tools/import.py`）不带 `Origin` 头，照常放行。
