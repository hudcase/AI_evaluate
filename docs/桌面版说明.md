# 桌面版说明（v0.3.0）

> 结论先说：**不需要推倒重来。** 现有「本地 HTTP 服务 + 静态前端」这套结构，
> 恰好是桌面软件最容易落地的一种形态；缺的不是架构，是一层"外壳 + 运行时适配"。
> 本文记录这次改造做了什么、为什么这么做、哪些坑踩过、还差什么。

---

## 一、为什么判定可以继续（而不是重写）

打包成桌面软件，真正要满足的是这几条。逐条对照当前代码：

| 桌面软件的要求 | 现状 | 判定 |
|---|---|---|
| 不依赖联网 | 前端零 CDN、零外链字体、零构建；后端只用标准库 | ✅ 天然满足 |
| 单机安装不折腾依赖 | `pip` 依赖为 0，`sqlite3`／`http.server` 都是标准库 | ✅ 打包不会碰到 native wheel 问题 |
| 数据在本地、可备份 | 单文件 SQLite + 一个 media 目录 | ✅ 拷目录即备份 |
| 不暴露到局域网 | 默认绑 `127.0.0.1` | ✅ 已有 |
| 有自己的窗口、不是浏览器 | 原来用 `webbrowser.open` | ⚠️ 需补（本次做） |
| 端口被占也能起来 | 原来硬编码 8000 | ⚠️ 需补（本次做） |
| 安装到 Program Files 也能写数据 | 原来数据在程序目录 | ⚠️ 需补（本次做） |
| 能选本地文件／另存为 | 浏览器只给 `C:\fakepath\` | ⚠️ 需补（本次做） |
| 关窗口即退出、不留后台 | 无 | ⚠️ 需补（本次做） |
| 双击第二次不会起两套 | 无 | ⚠️ 需补（本次做） |

**为什么不用 Electron / Tauri 重写**：那等于把后端（9 个模块、37 个接口、9 张表的口径）
和前端（9 个页面、21 条指标的展示逻辑）全部重做一遍，换来的是同一个窗口。
而且本机 `pip` 不可用（内网无源），Node 生态同样装不了，重写反而会让"评审现场能跑起来"
这条硬约束失守。

## 二、三种运行形态

同一份代码，三种入口，区别只在"谁来开窗口"：

| 形态 | 入口 | 数据目录 | 用在哪 |
|---|---|---|---|
| 桌面版 | `启动桌面版.vbs` 或 `python desktop/main.py` | `%LOCALAPPDATA%\EvalConsole\data`（便携模式见下） | 交付给最终用户 |
| 本地网页 | `start.bat` / `python backend/app.py` | `software/data` | 开发调试 |
| 打包 exe | `python build_win.py` 产物 | 同桌面版 | 无 Python 环境的机器 |

托盘/窗口形态三级降级，`desktop/shell.py` 里显式实现，启动日志会写明用的是哪一种：

1. `webview` —— 环境里若装了 `pywebview` 就用它（真原生窗口，可在 JS 里直接调 Python）；
2. `edge-app` —— **当前实际使用**。调 `msedge.exe --app=<url>`，无地址栏、无标签页、
   独立 `user-data-dir`（不污染用户日常浏览器的书签与登录态），独立任务栏条目；
3. `browser` —— 兜底，交给系统默认浏览器。

### 数据目录三种落位（`backend/config.py`）

```
源码运行            <项目>/software/data
打包 exe            %LOCALAPPDATA%\EvalConsole\data
便携模式            exe 同级存在可写 data\ 目录 → 就用它（U 盘拷走即用）
```

`EVAL_DATA_DIR` 环境变量优先级最高，压测／演示可随时指到别处。

## 三、这次加了什么

### 后端

| 文件 | 作用 |
|---|---|
| `desktop/main.py` | 桌面入口：起服务（线程）→ 开窗口 → 等退出信号 → 收尾 |
| `desktop/shell.py` | 窗口形态：webview／Edge app／浏览器；窗口前台化、按标题关闭 |
| `desktop/instance.py` | 单实例：`data/runtime.json` + 真实探活（不信文件，信 `/api/health`） |
| `backend/config.py` | 冻结路径适配（`_MEIPASS`）、`LOCALAPPDATA`、便携模式、日志目录、端口白名单 |
| `backend/core/native_win.py` | 纯 ctypes 调 Win32：选文件夹／选文件／另存为／资源管理器定位／错误弹窗 |
| `backend/scan_dir.py` | 目录树 → 批量入库清单（与 `tools/import.py scan` 同一套约定） |
| `backend/modules/m9_desktop.py` | `/api/desktop/*`：能力探测、原生对话框、目录扫描、报告另存、退出、生命周期信号 |

`app.py` 之外没有改动任何业务口径：探针、门禁、计分、融合、报告一行没动。

### 前端

| 文件 | 改动 |
|---|---|
| `assets/js/desktop.js` | 新增。能力探测 + 原生调用；**浏览器模式下所有方法返回"不可用"** |
| `app.js` | 桌面版才有「退出」按钮与「桌面版」徽标；页面心跳与关闭信号 |

前端做了能力收敛：`Desktop.isDesktop()` 为假时，原生按钮**根本不渲染**——
界面里不会出现"点了没反应"的按钮。

## 四、生命周期：踩过的两个坑

### 坑 1：不能盯浏览器进程

第一版用 `proc.wait()` 判断"窗口关了"，结果启动后约 35 秒应用自己退了。
原因：Edge 的 `--app` 启动器把窗口交给已有浏览器进程后**立刻返回**，`Popen` 结束了，
窗口还开着。

改成看**页面的一手事实**：

```
页面每 20s → GET /api/desktop/ping        （页面还在）
关窗口/刷新 → POST /api/desktop/bye       （页面要走）
```

### 坑 2：关闭信号不能直接退

刷新页面同样触发 `pagehide`，直接退就把用户踢出应用。所以：

- `bye` 只挂 3 秒倒计时，新页面载入 `info()` 会把它抵消（刷新无感）；
- 看门狗收到倒计时到期后，**再按窗口是否存在复核**，最多复核 8 次（16 秒）；
- 窗口一直在 → 判定为刷新/页面休眠，撤销退出；窗口没了 → 退出。

另有一条兜底：5 分钟没有任何 ping 则退出（页面崩了不会留下孤儿进程）。

### 退出时会发生什么

窗口关掉（或点界面「退出」）→ 停 HTTP 服务 → 关窗口（`WM_CLOSE`，兜住启动器提前退出的情况）
→ 删 `runtime.json` → 进程退出码 0。

实测：发关闭信号后 **2 秒内**端口释放、`msedge.exe` 归零、主进程退出码 0。

## 五、安全：把"本机端口"当公网对待

单机应用最容易忽略的一条：后端在 `127.0.0.1:8000` 上，**浏览器里任何一个网页都能向它发请求**。
表单 POST 属于"简单请求"，连预检都不发，读不到响应也足以把数据改掉。

原来 `Access-Control-Allow-Origin: *` 让这件事更毫无阻拦。这次收紧：

1. `ALLOW_ANY_ORIGIN` 只在 `--host 0.0.0.0`（局域网演示）时为真，其余只回显本机来源；
2. 写操作（POST/PUT/PATCH/DELETE）入口处校验 `Origin` 与 `Sec-Fetch-Site`，跨站一律 `403 FORBIDDEN`；
3. 会写盘的接口（`/api/desktop/save-report`、对话框）只在桌面模式开放，且是 POST——
   不能是 GET，否则别的页面放一个 `<img src=...>` 就能触发任意路径写入。

`tests/smoke.py` 已用三条断言钉住：跨站 403、本机来源放行、无 Origin 的本地脚本放行。

## 六、打包

```bash
python build_win.py            # 目录版（推荐，启动快）
python build_win.py --onefile  # 单文件 exe（拷一个文件就走，首启慢几秒）
python build_icon.py           # 只重新生成图标 assets/app.ico
```

需要 `pip install pyinstaller`。**本机当前装不上（内网无源），所以本次没有产出 exe**，
用 `启动桌面版.vbs` 直接跑源码，功能完全一致——这是刻意的降级路径，不是权宜之计：
`vbs` 检测到 `dist\...\*.exe` 就优先跑 exe，没有就退回源码，用户不需要知道区别。

打包时随包带走的数据文件（`build_win.py` 里的 `ADD_DATA`）：

```
frontend/            → frontend/           静态页面
backend/schema.sql   → backend/            建表语句
backend/seed/        → backend/seed/       指标种子
```

## 七、已知缺口（别当成已完成）

1. **任务栏图标仍是 Edge 的**。`--app` 模式没法换图标，只有 `pywebview` 或真正的 exe 才能。
   界面的 favicon 是我们的（蓝底 AE），窗口标题栏左侧也是。
2. **没有代码签名**。用户首次运行会被 SmartScreen 拦一次，需点"仍要运行"。
3. **没有自动更新**，也没有安装器（Inno Setup / MSIX 都没做）。
4. **ffmpeg、ASR／语音特征模型仍需外置**：转码抽帧、真实算分依赖它们，
   和桌面化无关，但装机时要一起考虑（放 `data/tools/` 或加入 PATH）。
5. **Edge 依赖**：`--app` 模式要求机器上有 Edge（Win10/11 自带，Win7 无）。
   没有 Edge 且没有 pywebview 时，会退回默认浏览器——能用，但不像桌面软件。
6. **剪贴板／拖拽**：还没接"把文件夹拖进窗口就直接扫描"，目前要点头选目录。
